For loop

For loops is used to iterate over a sequence such as a list, tuple, string or range. It executes a block of code once for each item in the sequence.

While loop

While repeatedly executes a block of code as long as the given condition remains true. When the condition becomes false, the line immediately after the loop in the program is executed.
